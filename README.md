# 考研数学题解库

十所院校的高等代数与数学分析考研真题题解，共 180 题。每题按固定结构展开：

**题目 → 题型识别 → 解题思路推演 → 正式解答 → 验证 → 易错点 → 同类题信号**

「解题思路推演」保留了思路试错的过程，包括走过的弯路和被否掉的方案，不是只给最终答案。

在线访问：https://zrx-11.github.io/exam-solver/

## 目录结构

```
exam-solver/
├── index.html      # 站点入口：目录、搜索、阅读视图
├── data.js         # 由 solutions/*.md 生成的题目数据（含全文）
├── vendor/         # KaTeX 与 marked，公式渲染所需，已本地化
├── solutions/      # 180 篇题解 Markdown，按「院校-科目-序号」命名
│   └── index.md    # 双链索引，可直接放 Obsidian
└── _scripts/
    └── build_data.py   # 重新生成 data.js
```

## 使用

直接打开 `index.html` 即可阅读，公式由页面内的 KaTeX 渲染，不依赖外网 CDN。

左侧目录按院校和科目分组，题号可点击跳转，读过的题目带一个小圆点标记。顶栏搜索覆盖题干、考点与易错点全文。手机上目录收进抽屉，从左上角按钮打开。

## 重新生成数据

改了 `solutions/` 里的 Markdown 之后：

```bash
python _scripts/build_data.py
```

脚本会重新扫描目录、解析文件名、抽取题干与题型，并覆写 `data.js`。
